## 📁 Proyectos Principales

### 1. Sistema de Punto de Venta

* **Stack:** Java, Spring Boot, MariaDB.
* **Características:** Implementación de arquitecturas limpias para asegurar escalabilidad y mantenimiento del código.

### 2. Sistema de Administración Hotelera
Solución para la administración integral de complejos hoteleros.
* **Stack:** Java (Programación Orientada a Objetos).
* **Características:** * Gestión de jerarquía de personal y control de activos.
